Slack アプリを作成

SockDock 用の Slack アプリを作ります。

  1. 必要な設定が入った作成画面が開きます。ワークスペースを選び、［Create］を押してください。
  2. そのアプリをインストールし、Bot Token（xoxb-）をコピー
  3. 同じアプリで App-Level Token を発行し（スコープ: connections:write）、xapp- で始まるトークンをコピー
すでにある Slack アプリを使う

次の設定をそろえてください。

Socket Modeオン
イベントmessage.channels message.groups
Bot Token のスコープchannels:history groups:history chat:write reactions:write
（channels:read groups:read は任意）
App Manifest の同じ場所に足してください。

Socket Mode をオンにすると、このアプリのイベントは SockDock にだけ届くようになります。

設定を変えたら、アプリを再インストールしてください。
