Slack アプリを作成

SockDock を使うには、専用の Slack アプリが必要です。Slack の管理画面で、次の 3 つを行ってください。

  1. アプリを作成（設定は入力済みです）
  2. ワークスペースにインストール → Bot Token（xoxb-）が発行されます
  3. App-Level Token を発行（スコープ: connections:write）→ xapp- で始まるトークン
